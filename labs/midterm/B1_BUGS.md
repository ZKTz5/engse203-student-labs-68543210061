## วิธีกรอก (อ่านก่อนเริ่ม)

กรอกให้ครบ **ทั้ง 6 บั๊ก** · แต่ละบั๊กเขียน 3 อย่างด้วย **คำของตัวเอง** (จะถูกสุ่มถามใน oral)

| คอลัมน์ | ใส่อะไร | ตัวอย่างสิ่งที่เขียน *(บั๊กสมมติ)* |
|---|---|---|
| **ไฟล์ : บรรทัด** | ไฟล์ที่แก้ + เลขบรรทัด | `Foo.jsx : 12` |
| **สาเหตุ** | **ทำไม** มันทำงานผิด (ไม่ใช่แค่ "พิมพ์ผิด") | "ใส่วงเล็บท้ายชื่อฟังก์ชัน เลยถูกเรียกทันทีตอน render" |
| **แก้อย่างไร** | เปลี่ยน**จากอะไร**เป็น**อะไร** | "เอาวงเล็บออก จาก `onClick={fn()}` เป็น `onClick={fn}`" |

> เคล็ด: เลขบรรทัดดูได้จากแถบซ้ายใน VS Code หรือจากข้อความ error ใน Console (เช่น `RequestList.jsx:9`)

## บันทึกของฉัน — กรอกทั้ง 6 บั๊ก

| # | อาการ (ให้มาแล้ว) | ไฟล์ : บรรทัด | สาเหตุ (ทำไมผิด) | แก้อย่างไร |
|---|---|---|---|---|
| 1 | Console เตือนสีเหลืองเรื่องรายการ (list) | `src/components/RequestList.jsx : 9` | มีการใช้ `.map()` เรนเดอร์ `<RequestCard/>` แต่ไม่ได้ใส่ `key` ทำให้ React ระบุตัวตนของการ์ดแต่ละใบไม่ได้ | เพิ่ม `key={request.id}` ให้กับคอมโพเนนต์ `<RequestCard/>` ในฟังก์ชัน `.map()` |
| 2 | ตัวเลข "รอดำเนินการ" ในแผงสรุปไม่ตรงกับที่เห็นจริง | `src/pages/DashboardPage.jsx : 47` | ใน `summary.pending` มีการกรองเงื่อนไข `status === 'completed'` แทนที่จะเป็น `pending` | เปลี่ยนจาก `status === 'completed'` เป็น `status === 'pending'` |
| 3 | กดตัวกรอง "รอดำเนินการ" แล้วได้รายการที่ไม่ใช่ | `src/pages/DashboardPage.jsx : 55` | มีการใช้เงื่อนไข `status !== statusFilter` ทำให้แสดงการ์ดที่มีสถานะไม่ตรงกับปุ่มฟิลเตอร์ที่กด | เปลี่ยนเงื่อนไขจาก `status !== statusFilter` เป็น `status === statusFilter` |
| 4 | เปลี่ยน URL `REQ-001` → `REQ-002` แล้วข้อมูลไม่เปลี่ยน | `src/pages/RequestDetailPage.jsx : 28` | ใน Dependency Array ของ `useEffect` มีแค่ `[reloadKey]` ขาด `requestId` ทำให้เมื่อ URL เปลี่ยน React ไม่ดึงข้อมูลใหม่ | เพิ่ม `requestId` ลงใน Dependency Array เป็น `[requestId, reloadKey]` |
| 5 | กด "ลบ" แล้วรายการยังอยู่ ต้องรีเฟรชถึงหาย | `src/pages/DashboardPage.jsx : 65` | ใน `handleDelete` มีการส่ง `requests` เดิมเข้า `setRequests()` ทำให้หน้าจอไม่อัปเดตด้วยข้อมูลชุดใหม่ | เปลี่ยนเป็น `setRequests(nextRequests)` โดยนำ Array ผลลัพธ์ใหม่ที่ได้จาก `deleteRequest()` ไปอัปเดตลง State ทันที |
| 6 | กด "Reset Demo Data" แล้วหน้าพัง/ว่างเปล่า | `src/pages/DashboardPage.jsx : 75-76` | ฟังก์ชัน `resetRequests()` เป็น async แต่ไม่มีคำสั่ง `await` ทำให้ได้ค่า Promise ไปเก็บใน State แทนที่จะเป็นข้อมูล Array | ใส่ `await` หน้า `resetRequests()` เป็น `const nextRequests = await resetRequests(); setRequests(nextRequests);` |
